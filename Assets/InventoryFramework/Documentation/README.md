# Inventory Framework

A flexible, modular inventory system for Unity.

## Project Structure

```
Assets/
├── InventoryFramework/          (main package folder)
│   ├── Core/                    (Milestone 1 - core systems)
│   │   └── InventoryFramework.Core.asmdef
│   ├── Extensions/              (Milestone 2 - rule blocks, etc.)
│   ├── Editor/                  (Milestone 3 - UI wizard)
│   ├── Samples/                 (demo items, test scenes)
│   └── Documentation/           (project documentation)
└── _DevTest/                    (scratch area, not for export)
```

## Development Milestones

### Milestone 1: Core Systems
- Item data structure
- Inventory container logic
- Slot management
- Basic item placement

### Milestone 2: Extensions
- Rule blocks
- Custom behaviors
- Advanced features

### Milestone 3: Editor Tools
- Visual UI wizard
- Inspector customizations
- Development tools

## Getting Started

1. Core systems are in `InventoryFramework/Core/`
2. Use `_DevTest/` for experimental work
3. Assembly definitions enforce clean dependencies
